# CCF – post-review exploratory message-loss panel (v25)

## Status / scope

This is a **local, post-review exploratory** benchmark conducted in the author-built synthetic event-driven system. It is **not an external preregistration**, an independent-host reproduction, a public DOI deposit, a field-calibrated workload, or a comparison of universally optimized algorithms. The 12 new world seeds are only seed-disjoint within the same authored generator. The local atomic guard is instantaneous, lossless, and not charged for processing or network cost in **all arms**. The service manager uses request/grant/release packets, so it has a different number and role of loss opportunities from DRA peer claims. Do not interpret completion gaps as intrinsic algorithm superiority.

## Data overview

`results/episodes.csv` includes all **4,320 attempted episodes**: 12 worlds × 3 trial seeds × 5 message loss rates × 2 horizons × 2 guards × 2 stress laws × 3 arms, grouped in **1,440 matched triplets**. There are no execution failures. `results/failures.json` records failed runs (empty in this release). `results/summary_by_cell.*` contains 40 stratum summaries. The analysis resamples the twelve world means, not all repeated episodes as independent observations.

## Reproduce from this archive

This archive uses only the Python standard library for simulation and analysis (CPython 3.11+ recommended). Run from its extracted root:

```bash
python3 analyze_postreview_loss_sweep.py results
```

This recomputes the CSV-derived summaries, failure counts, 4,000-replicate world-cluster intervals, and `results/audit.json`. For the entire original synthetic run (modifies result files, and may take several minutes on a slower host):

```bash
python3 run_postreview_loss_sweep.py results
python3 analyze_postreview_loss_sweep.py results
```

The `source/CCF_v15_Reproduction_Candidate_20261123` subtree contains exactly the needed, unchanged original engine, world generator, and sharded manager classes. The historical publication comparisons quoted in the article are **not** regenerated by this compact supplement; they remain in their separate historical author-held archives. The Matplotlib figures supplied here were generated from `results/summary_by_cell.json` using the separately authored figure script (Matplotlib optional). Check `SHA256SUMS` against every extracted archive file. No remote repositories are accessed by this package.
