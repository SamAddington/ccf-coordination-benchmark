# v26 Companion Reproducibility Package

**Manuscript:** *Client Fallback and Control-Plane Placement Reverse Coordination Rankings Under Message Loss* (IEEE Access template manuscript, 24 November 2026).

## Scope and evidence boundaries

All records were generated by Python on a single ChatGPT computational environment from the supplied event-driven CCF simulator and source-derived v25 components. The data are synthetic, post hoc exploratory, and not an author-run or independent laboratory replication. The 4,320-row v25 dataset is preserved unchanged as a separate historical stratum; it must not be pooled as new observations with the 2,592-row primary v26 comparison.

Contents:

- `v25/`: original 4,320-episode source/evidence release, historical parameters and manifest.
- `fairness/fair_engines.py`: new clients (fallback, cancellation, replays, co-located manager, modeled remote guard).
- `fairness/run_fair_comparison.py`: main 2,592-episode experiment, all attempted results retained.
- `fairness/results/episodes.csv`: 2,592 records across **72 combinations** = 9 arms × 4 independent message-loss rates × 2 deadlines; each condition has 12 worlds × 3 trial seeds.
- `fairness/results/all_72_cells_with_intervals.csv`: complete per-arm-per-condition means and descriptive 95% world-cluster intervals.
- `fairness/results/paired_world_contrasts.csv`: selected precomputed contrasts; other contrasts can be derived from the raw records.
- `fairness/sensitivity.py`: 1,680 additional source-executed episodes for low loss, TTL, timing, 16 agents and correlated loss.
- `fairness/sensitivity_results/episodes.csv`: full sensitivity records.
- `fairness/build_analysis.py`: regenerates main summary interval tables and figures; requires matplotlib for plots.
- `fairness/verify_v26.py`: separate same-host deterministic source and numerical checks.
- `manuscript/`: final Word/PDF article and revision response.
- `SHA256SUMS`: SHA-256 checksums for every other file in the archive, relative to the extracted root.

## Running checks

With CPython 3.11 or later, from the archive root:

```bash
python3 fairness/verify_v26.py
```

This checks record counts, complete condition grid, per-condition summary parity, 27 deterministic source replays (162 checked numeric metrics), world-seed separation from the v25 historical study, and sensitivity episode counts. It should print `"pass": true`.

To regenerate every primary episode in a new output directory without overwriting the archived data:

```bash
python3 fairness/run_fair_comparison.py fairness/reproduced_primary
```

To regenerate the full sensitivity study:

```bash
python3 fairness/sensitivity.py fairness/reproduced_sensitivity
```

To regenerate summary/plots from the **archived** primary CSV (requires `matplotlib` for plots):

```bash
python3 fairness/build_analysis.py
```

The simulator uses Python standard-library APIs apart from matplotlib in the plotting pass. It does not require target network access, external agents, penetration-testing tools or credentials.

## Interpretation limits

- Every arm uses authored synthetic tasks, service capacities, independent trial outcomes, and an original stress law.
- In the *local-guard* case admission is an idealized instantaneous atomic check. In the *remote-guard* case admission is a modeled request/reply path on the same lossy transport. This changes delay and failure opportunities.
- `permit_colocated` assumes lossless instantaneous authority RPCs, not real cluster deployment.
- `permit_fallback` is bounded fallback, **not** an optimized work-conserving queueing algorithm.
- Packet counts are simulator events, not measured bytes, CPU usage or round-trip time from a real network.
- No independent researcher or separate physical host has reproduced these results; archive accessibility and DOI publication must be handled separately by the author.

The author remains responsible for paper, citation and source-license verification before submission.
