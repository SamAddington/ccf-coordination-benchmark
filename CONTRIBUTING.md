# Contributing

Issues and pull requests for documentation errors, reproducibility improvements and additional baselines are welcome after the repository becomes public. Contributions modifying the reference simulator should be **new, clearly identified experiments** and must not overwrite frozen episode CSVs or the primary baseline without creating a separate experimental version.

Please include reproduction commands, Python version, source revision, any code provenance/third-party license notices, the full attempted-run record (including failures), and a description of which existing claims the change affects. The author retains responsibility for deciding whether to merge or to cite contributed results in a paper.
