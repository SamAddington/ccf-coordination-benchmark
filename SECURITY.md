# Security policy

This is a synthetic benchmarking project, **not** a hardened security product or an active cyber-assessment tool. It should not be pointed at external services or used to justify unreviewed production admission policies.

For security concerns about scripts or dependencies, open a private report through GitHub's security-advisory feature if available, or contact the repository maintainer through a private channel. Do not post credentials, client identities, or sensitive logs in public issues.
